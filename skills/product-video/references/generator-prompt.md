# External video generator handoff

Use when the user requests a prompt, or chooses a capable external image-to-video service. Provide copy-ready English by default for this user's handoffs. Substitute only facts supported by the current inputs. Do not assert that the service can render faithful hidden surfaces or flawless text.

Build the prompt around:

1. **Purpose:** platform, premium/other audience, what inspection or specification information the clip must add.
2. **Authoritative sources:** exact target photos/model; separately label finish or construction examples. State which product/variant is shown.
3. **Identity lock:** silhouette, handle shape/asymmetry, body thickness, joints, components and finish. Natural source midtones control brass colour; no warmer orange/gold grading.
4. **Confirmed dimensions:** values, units and endpoints. Separate observations from confirmed measurements. Explicitly exclude known superseded/incorrect facts relevant to this product.
5. **Shot plan:** useful close-ups, controlled movement, legible sequential measurements and full-product closure within the requested duration.
6. **Single-image constraint:** permit only source-faithful movement when unseen geometry cannot be established. Do not turn a request for unchanged details into permission to invent a rear or side view.
7. **Material/style:** neutral photographic studio, realistic metal reflections, faithful surface character, restrained typography; adapt to the user's requested style.
8. **Text fallback:** if reliable letters/numerals cannot be generated, request a clean movie plus timecoded overlay plan so measurements can be added deterministically. Never accept garbled or changing values.
9. **Output and review:** actual duration cap, resolution/aspect ratio, codec, audio choice, no watermark; frame-by-frame check for shape drift, colour shifts, wrong parts and wrong dimensions.

Useful fidelity wording:

> The attached original image is authoritative. Preserve every visible product detail and the existing finish. Do not redesign, simplify or invent components. A single image does not establish unseen geometry. Use an orbit only if the supplied references genuinely support it and the product remains consistent; otherwise use informative detail shots and measurement animation. Fidelity takes priority over dramatic movement.

For exact-detail work, do not state that the result is guaranteed identical. Review it against the source, and prefer conventional source-photo editing or an accepted actual model if generation changes the product. Do not claim a video was created when delivering only a prompt.
