# Official guidance

Verified November 27, 2026. Recheck relevant pages for the run unless already checked in the same session. Update hard constraints and checker together if rules change.

- [Create a listing](https://help.etsy.com/hc/en-us/articles/115015628707-How-to-Create-a-Listing): title maximum **140 characters**; consider **fewer than 15 words**; clear product and essential traits. Avoid repetition, subjective filler and price/shipping in titles. Description should explain what the buyer receives with natural search language.
- [Title guidance](https://www.etsy.com/seller-handbook/article/1399426136697): clear buyer-friendly identity and traits; title, tags, attributes and description work together. Do not fill 140 characters by default or treat the word recommendation as a platform hard limit.
- [Tag rules](https://help.etsy.com/hc/en-us/articles/360000336307-How-to-Use-Tags-to-Get-Found-in-Search): up to **13 tags**, each at most **20 characters**, using permitted letters/numbers/spaces/apostrophes/hyphens. Apostrophes/hyphens cannot begin a tag. This workflow delivers 13 when supportable.

Do not apply narrower advertising advice about very short titles as a universal listing limit. No verified universal description word count or keyword density exists.

Metric interpretation:

- [Google Autocomplete](https://support.google.com/websearch/answer/7368877): multiple language/location/history signals; suggestions are not a volume-ranked list.
- [Google Trends](https://support.google.com/trends/answer/4365533): normalized relative interest (0–100), with low-volume zeroes possible. Separate charts are normalized independently; Google interest is not Etsy demand.
